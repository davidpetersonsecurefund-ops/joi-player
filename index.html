Setup guide (about 10 minutes)
  1. Go to console.cloud.google.com and create a new project.
  2. APIs & Services, Library: enable the Google Drive API.
  3. OAuth consent screen: choose External, fill the basics, add the scope .../auth/drive.file, and add your own Google address as a test user.
  4. Credentials, Create credentials, OAuth client ID, type Web application.
  5. Under Authorized JavaScript origins add your site address with no path (like https://yourname.github.io).
  6. Copy the Client ID into the box above and tap Sign in. If sign-in stops working after about a week, switch the consent screen from Testing to In production.

Heads-up: Google can scan files in Drive, and its rules cover explicit content. Use a separate Google account made just for this.
